# 公开站点技术方案

> 2026-09-22。需求依据：[落地页改造 PRD](Trade%20Lab%20落地页改造%20PRD.md)及后续界面反馈。页面已实现；协议为用户授权编写的待确认草案，支付仍未接入。

## 页面与入口

| 英文 | 中文 | 内容 |
| --- | --- | --- |
| `/` | `/zh-CN` | 主副标题、真实研究输入、四个示例、BUILD → TEST → LEARN 研究闭环、业务边界；中英双语 |
| `/pricing` | `/zh-CN/pricing` | 复用 `PricingContent` 与 `PlanCard`，静态 USD 价格及积分、计费说明 |
| `/privacy` | `/zh-CN/privacy` | 隐私政策草案 |
| `/terms` | `/zh-CN/terms` | 服务条款草案 |
| `/refunds` | `/zh-CN/refunds` | 301 跳转到对应语言的 `/pricing#billing`，取消与退款说明合入价格页 |
| `/contact` | `/zh-CN/contact` | 运营主体、品牌关系和支持邮箱；未配置时仅说明待补齐 |
| `/open-source` | `/zh-CN/open-source` | 原有第三方开源署名 |

内容页面使用 `public` 布局和 SSR，无需登录，已登录也不会自动跳往工作台。顶栏登录状态在 mounted 后显示，避免认证恢复早于 hydration 时产生链接与文字不一致。顶栏仅保留价格、语言与账号入口；手机账号入口收在菜单内。公共顶栏统一高 60px，固定在视口顶部，布局预留等高空间；使用浅／深色主题的 `--color-bg-public-header` 半透明背景及 12px 背景模糊。研究流程和价格说明锚点预留 84px 滚动间距，避免被顶栏遮挡。语言触发器悬停、展开和聚焦保持透明，仅用文字、箭头与按下透明度反馈；Logo 字标悬停保持正文色。公共语言菜单通过 `PreferenceSelect modal=false` 使用非模态下拉，不锁定 body 滚动或移除滚动条，避免固定顶栏开合时横向位移；共享控件在其他位置仍默认模态。价格、语言和账号入口预留稳定宽度，切换中英文不挤动相邻入口。首页保留研究流程正文，不提供顶部流程导航。页脚仅保留价格、隐私、条款和联系入口，不显示历史表现提示。开源声明保留原页面及许可证文件，入口移至服务条款正文，以保留可访问的第三方署名。

`ResearchEntry` 新增可选 `examples: { label, prompt }[]`，落地页单独传入占位与示例；工作台保留原文案。Reversal 填入趋势反转，不使用均值回归。示例只填入并聚焦，不发送；挂载前、明确提交中或存在待处理提交时禁用，防止无效点击或覆盖原提交。草稿、登录恢复、取消与幂等继续使用原 controller，不写第二套提交逻辑。

落地页、新研究页和对话页输入框统一为最大 736px，共用 `--conversation-width`。首页研究绘图区可扩展至 960px，以 BUILD → TEST → LEARN → BUILD 表达闭环。初始想法在环外，以星芒和“一个想法”从上方进入 BUILD；回路线从 LEARN 完整节点下方直接接回 BUILD，不经过初始想法。BUILD 用行情想法气泡、条件分支与 B/S 动作表达 AI 将假设转为规则和策略；TEST 将同样的 B/S 以带引线的标签标到 K 线上，并保留回放进度线；LEARN 用两种结果、放大镜与问号气泡表达对比证据并提出下一轮问题。B/S 共用浅金色样式，以字母区分买卖，不复制产品红绿交易配色。每个节点将图示、标题和精简说明放在一起，不用卡片边框分隔；桌面回路线位于全部图文下方，手机使用左图右文的三行，左侧回路线直接连接 BUILD。已移除额外的结果总结句。

星芒由 `IntersectionObserver` 在首次完整进入视野时触发一次 1500ms 的轻亮，随后静止；卸载时清理观察器，`prefers-reduced-motion` 下不播放。线路和节点不循环闪动、不可点击。装饰性 SVG 对辅助技术隐藏，步骤保留有序列表语义；图示不含模拟收益或虚构业务结果。首屏主标题和已定稿副标题保留，副标题同步用于首页 SEO 描述。

## 语言与偏好

- Nuxt i18n 使用 `prefix_except_default`，默认 `en-US`，中文前缀 `/zh-CN`。公开页面语言由 URL 确定，深链不受账号、浏览器语言或旧 Cookie 改写。
- `/login`、`/new-task`、`/conversations/:id` 使用 `defineI18nRoute(false)`，资源地址不因语言变化而改变。未生成 `/zh-CN/new-task` 等私有别名，避免扩大鉴权、缓存和索引边界。
- 只有语言控件的主动选择写入一年有效的 `trade-locale-manual` Cookie，刷新和退出登录均保留。旧 `trade-locale` 无法区分手动选择与自动默认值，因此不迁移；首次无记录默认英文。
- 公共语言切换导航到同页对应语言地址，保持 query/hash 和当前标签页草稿。默认首页 `/` 在存在手动中文偏好时以 302 导向 `/zh-CN`，保留 query/hash；无记录时展示英文。切回 EN 先写偏好再导航，避免重定向循环。其他公开深链语言由地址决定；站内返回首页使用当前语言地址。根路径设置 private/no-store 与 Vary: Cookie，避免偏好跳转被共享缓存。
- 私有页面按手动偏好、已登录账号语言、当前浏览会话语言、英文依次恢复；初始 SSR 不读取私有账号数据。身份恢复不改写公开页面语言，也不伪装成一次手动选择。

## 价格与首发能力

`/pricing` 与工作台弹窗直接嵌入同一个完整 `PricingContent`，包含共享标题、会员套餐／积分加购页签、套餐卡片、快捷／自定义金额与支付待上线提示；不再保留 `publicPage` 分支或价格页卡片专用样式。公开页仅指定 `headingTag="h1"`；当前套餐由共享组件在挂载后跟随现有认证状态，已登录时与工作台一致，显示静态 Free 预览为“当前套餐”。访客或身份恢复中不标记当前套餐，显示禁用的“免费套餐”，加购表单标为 Free 加购单价示例。两处均无“开始研究”入口。Pro/Max 及有效加购都触发同一 `checkout` 处理和 2.2 秒待上线提示，不生成订单。切换页签保留本次金额，研究草稿不会被价格导航清空。

套餐下方问答、积分说明与消耗示例表共用卡片区域的完整内容宽度，左右边缘对齐，不再单独限制段落与表格宽度。按用途、典型消耗、额度用完后的选择及取消退款组织短段落。用户授权先用示例数据：讨论／解读约 1–5 积分，生成／修改策略约 10–30 积分，回测与分析约 20–60 积分；标注消耗示例与待确认边界。按月刷新、加购、已有内容不重复计费及取消续费规则均属方案文案，不代表后端已执行。退款说明不预设退款天数或无条件退款承诺。

表达结构参考 [ChatGPT 积分说明](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt) 的用途、典型消耗与加购说明，以及 [YouMind 价格页](https://youmind.com/en-US/pricing?campaign=2026-618) 的月度额度和简短问答结构。数字为 Trade Lab 自拟示例，并非引用竞品费率。开源入口调整依据 [Lightweight Charts 署名说明](https://github.com/tradingview/lightweight-charts#license)：保留用户可访问的 NOTICE 署名和 TradingView 链接，不要求固定占用全站页脚。

支付、订单、真实订阅识别、积分余额及扣费没有接入，因此不实现虚假的选择套餐后支付成功流程。公共页与工作台的购买入口由共享组件维护，未来接入认证及真实会员、订单与支付后，两处共用同一支付流程，直接进入支付，无额外确认页。

首发 `NUXT_PUBLIC_ENABLE_RUNNER_DOWNLOAD=false`，策略详情下载入口和下载弹窗不挂载；原代码仍可用于后续明确开放。本开关不改变后端接口权限或服务配置，正式首发还需后端核对是否开放运行包接口。

## 协议与联系信息

`PublicDocument` 提供 720px 正文阅读宽度、标题、日期与草案说明；`LegalDocument` 读取隐私与条款的中英文同构正文。取消与退款合入价格页，原 `/refunds` 地址只保留对应语言的重定向。政策说明已知账号、研究内容、AI 处理和本地草稿行为，待确认的供应商、训练使用、保存/删除周期、正式计费规则、法律适用和争议处理明确留待补齐。

用户已允许先按产品编写，运营主体之后提供。没有编造公司、邮箱、退款天数、无限使用或数据不用于训练等承诺。`NUXT_PUBLIC_OPERATOR_NAME` 与 `NUXT_PUBLIC_SUPPORT_EMAIL` 用于后续填入真实主体与已验证邮箱；有合法邮箱格式时渲染 `mailto:`，无值时不生成虚假链接。

登录页始终提供条款及隐私链接，使用新标签页保留邮箱、验证码流程和待提交研究。尚无正式协议时仅显示“查看我们的”，不把草案表示成已生效的用户同意。原 `TERMS_URL` / `PRIVACY_URL` 配置作为可选外链覆盖保留，默认使用本地化内部页面。

隐私目录参考 [ICO 的隐私告知项目清单](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/individual-rights/the-right-to-be-informed/what-privacy-information-should-we-provide/)（2026-09-20 读取），仅用于检查内容类别，不据此假定适用地区或宣称合规。

## SEO 与部署

- `usePageSeo` 输出每页标题、描述、HTML 语言、自指 canonical、en-US / zh-CN / x-default 对应关系及 1200×630 分享图。
- 默认正式域名 `https://speakquant.com`，可通过 `NUXT_PUBLIC_SITE_URL` 覆盖；正式部署不要保留 localhost。
- `server/routes/sitemap.xml.ts` 只列首页、价格、开源说明的两个语言版本。隐私、条款与联系页目前为 `noindex, nofollow`，直到信息核准再调整共享索引清单和页面索引设置。退款旧地址重定向，不单独索引。
- `robots.txt` 提供 sitemap，不阻止搜索引擎读取页面的 noindex。私有页面保留 `X-Robots-Tag: noindex, nofollow` 与 `Cache-Control: no-store`；工作台仍为 CSR，认证边界不变。
- 未知 URL 返回 404，错误页 noindex。只新增公开静态内容路由，无 API 代理或 BFF。
