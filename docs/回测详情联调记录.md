# 回测详情联调记录

日期：2026-09-16。实现契约见[回测详情模块技术方案](回测详情模块技术方案.md)。

## 实际接入

本轮实现全宽 K 线、成交量、十字线、成交/洞察标记、证据区间、固定 Timeline、逐 K 播放/暂停/倍速/事件跳转、全部指标/条件/报告、洞察与交易过滤/分页/成交明细、冻结策略节点往返、可移除追问引用、幂等重试和 ZIP 运行包下载。图表使用锁定的 Lightweight Charts 5.2.0，动态加载；公开 `/open-source` 和 `public/licenses/` 提供替代署名及许可证。

主行情用无范围 cursor 链建立完整索引，逐 K 原始页只保留 12 页，每页 2000 根；窗口预览最多缓存 400 条原始记录。Candle 并发上限 2，前台定位优先。关闭、换回测或换用户取消请求，迟到响应不写回；报告失败等仅影响所属资源。

多周期采用当前后端兼容扩展：只有响应 `available_timeframes` 后才启用切换；旧接口只显示执行周期。查看周期直接取后端 OHLCV，非执行周期不推算策略状态。开始播放切回执行周期，返回整体结果恢复查看偏好。

## 性能与边界

200000 根 Candle + 10000 笔交易的压力夹具采用真实分页与 Canvas。首次测量暴露了全量 SDK 反复绘制的高内存/长任务，因此改为有界视野：最多 4001 根可见真实 Candle，加两侧各 500 根缓冲。完整时间与事件索引保留，固定 Timeline 覆盖全区间；长证据区间先在图中看末端，Timeline 保留完整区间高亮。交易 DOM 每页最多 20 行。

单进程独立运行的本地开发环境测量（API 为分页 Mock，非生产网络）：

| 项目 | 桌面尺寸 | 手机尺寸 |
| --- | ---: | ---: |
| 首次 Canvas 可见 | 1.58s | 1.13s |
| 完整索引与交易加载、末端定位和采样完成 | 9.37s | 8.56s |
| 最大长任务 | 73ms | 62ms |
| 长任务数（>50ms） | 2 | 2 |
| 页面 JS 堆采样 | 415MB | 169MB |

这组数据用于定位退化，不作为生产 SLA。堆采样包含开发运行时、整个页面与未回收临时对象，受 GC 时机影响；不是图表保留内存。静止一秒的 RAF 采样均为 61 次，不等同于拖动 FPS。长任务仍有超过 50ms 的样本，未声称全程无阻塞。长历史补充操作验证连续拖动超过窗口缓冲后仍能选择真实 K 线，以及时间轴回到首根、关闭后 Canvas 清理。

- 手机项目是桌面 Chromium 的尺寸/触控模拟，不是 iPhone 真机；Safari、双指缩放、软键盘与后台切换尚无真机验收证据。
- ZIP 下载用模拟 ZIP 流验证了来源、目标参数、响应格式和保存；未真实生成/运行 Runner。开发环境后端未暴露 Content-Disposition 时，公共下载器回退 download.zip。
- 追问只验证前端真实发送结构及模拟重试，未提交真实 Agent 请求；服务端内容为原样显示，不将确定性分析器描述成逐 K AI 解释。
- 创建/重试/取消回测、策略恢复和 Runner 运行控制仍不在本轮范围。
