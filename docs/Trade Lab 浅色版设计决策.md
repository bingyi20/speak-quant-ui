> 更新日期：2026-09-20

## 1. 文档用途与决策状态

本文维护当前有效的视觉与交互规范，承接已确认的原型方向和正式前端修订。更新直接落在对应主题章节，不按每次修改追加流水账；业务流程由专项技术方案维护，验证结果进入联调记录。

- **已确认**：用户明确选择的方向、明确要求的行为与尺寸，应延续到后续版本。
- **原型参考**：当前页面实际使用的字体、辅助颜色、间距和动效等；可作为起点，但不等于每个数值都已逐项确认。
- **待打磨**：正式产品仍需设计、实现或验证的细节，不能把演示行为直接当作生产规格。

业务规则继续参考 [PRD](./Trade%20Lab%20MVP%20PRD.md)、[产品决策](./产品决策.md) 和 [MVP 交互方案](./Trade%20Lab%20MVP%20交互方案.md)。本文补充本轮浅色视觉及交互修订，不另建一套完整业务流程。原型与业务文档不一致时，应识别为待对齐项；不能因原型省略了功能，就推断该需求已经取消。

## 2. 核心设计方向（已确认）

### 2.1 产品气质

安静、清晰、理性、睿智，同时保留温度、金融研究的仪式感和发现问题时的兴奋感。

- 参考 Claude 的信息组织与克制程度：像与一位理性、睿智的人一起工作。
- 参考 Creem 的表达与反馈：可以形象、有个性、灵动，但注意力主次必须明确。
- 金融感通过精确的数字、图表、时间、证据与操作反馈建立。
- 兴奋感集中在策略形成、回测完成、关键事件及洞察出现的时刻。

参考网站：[Claude](https://claude.ai/)、[Creem](https://www.creem.io/)。参考的是体验取向，不复制品牌资产或整套样式。

### 2.2 表达纪律

> **非必要不解释，非必要不强调。克制不等于死板，灵动留在交互里。**

1. 同一个信息尽量只在一个适合的位置重点呈现。
2. 对话提供结论，Replay 提供指标、行情和证据。
3. 不用大量加粗、彩色数字、卡片、标签同时争夺注意力。
4. 不为表达“专业、可信、睿智”而反复增加说明性文案。
5. 删除无助于理解或操作的内容，而不是缩小字体、降低对比度来隐藏它。
6. 保留有意义的悬停、按下、展开、选中和定位反馈。

已删除的典型冗余包括：“研究伙伴”身份标签、“基于本次历史回测 · 可追溯的研究证据”、重复标语、对话内重复的收益大数字与装饰性小图。

## 3. 浅色主题与颜色

### 3.1 品牌主色（已确认）

**赭金 `#986B2C`**。

用户确认理由：有金融感，同时有一定区分度；温暖，符合产品气质。

使用方式：

- 少量用于品牌符号、发送按钮和主要操作。
- 保持纯色、低饱和、哑光的感觉。
- 不扩展为大面积金色背景，不添加金属渐变或发光效果。
- 正文和常规边框以中性色为主。
- 品牌色与涨跌、盈亏颜色分开承担语义；赭金不表示盈利。

**交互边框规则（已确认）**：交互保持克制、简洁、轻量。除非用户明确要求，不新增强调边框、选中描边或焦点外圈，金色、灰色均不例外；禁止把“去掉金色边框”实现为换一种颜色继续画框。按钮、链接和卡片在点击、键盘聚焦及 Esc 恢复焦点后，不新增 outline、ring 或模拟外圈的阴影，也不加深、加粗原有边框。共享样式默认不为按钮和链接绘制焦点轮廓，控件只使用轻微文字/图标颜色反馈；卡片只加深打开箭头，保留普通边框。保留实际焦点、Tab/Enter/Space 和分层 Esc 行为，不能用 blur 绕开样式问题。输入框自身的编辑焦点反馈、已有明确业务语义的选中态分别遵循对应组件规范。

### 3.2 页面基础颜色（本轮采用的基线）

## 4. 字体与排版

### 4.1 设计方向

- 日常对话与操作文字清晰、自然，适合长时间阅读。
- 首页标题带少量书卷感，形成温暖、沉静的气质。
- 指标数字清晰、有分量，但不在对话与 Replay 两处重复突出。
- 日期、时间和需要比较的数字保持稳定对齐。

### 4.2 当前原型字体（参考，尚未逐项定稿）

| 用途 | 字体栈 |
| --- | --- |
| 正文 / 通用 UI | `"Avenir Next", "PingFang SC", "Microsoft YaHei", sans-serif` |
| 首页标题 | `"Songti SC", "STSong", Georgia, serif` |
| 回测指标大数字 | `Georgia, "Times New Roman", serif` |
| 时间 / 部分数字元信息 | `"SFMono-Regular", Consolas, monospace` |

字体依赖系统可用字体回退，当前没有把上述字体打包为 Web Font。不同操作系统的结果不完全相同；正式产品需确认中英文字体、授权、加载与回退方案。

### 4.3 当前字号参考

- Agent 正文：`16px`，初始回复行高 `1.9`。
- 用户消息：当前 `14px`；正式产品需与 Agent 正文共同复核。
- 常用导航、操作和洞察标题：主要为 `14px`。
- 公共首页标题：桌面 `clamp(36px, 4.2vw, 61px)`，行高 `1.22`；小屏 `clamp(32px, 7.8vw, 48px)`，行高 `1.3`。
- 回测指标：通常 `29px`，小屏 `27px`。
- 次级信息主要为 `12–13px`，部分日期、图表和脚注仍小于 `12px`，需后续复核。

克制应通过精简与排版实现，不能用过小、过浅的文字代替信息取舍。

## 5. 全局布局与导航

### 5.1 页面结构

沿用左侧研究历史、中央对话、右侧按需展开资产的框架。首页聚焦输入研究想法，不增加行情仪表盘等无关入口。

正式前端桌面侧栏统一使用 `--sidebar-width: 260px`，左、右、下内边距均为 `8px`。`/` 是公共落地页，`/new-task` 是工作台新研究页，不把两个入口的外围布局混为一体。

落地页保留暖白画布、系统衬线主标题与赭金标点。首屏英文主标题采用[落地页改造 PRD](Trade%20Lab%20落地页改造%20PRD.md)定稿，中文主标题保持“3 分钟，验证你的交易想法。”。副标题采用用户最新中英文定稿：“Turn market ideas into evidence — explore, test, and refine strategies with AI.”／“让交易想法变成证据，与 AI 一起探索、验证并迭代策略。”，随可用宽度自然换行。真实输入与四个示例共享工作台控件，最大宽度 736px。下方研究绘图区放宽至最大 960px，以“从想法到证据，再从证据出发。”引入 BUILD → TEST → LEARN → BUILD。初始想法位于环外，以一颗小星芒和“一个想法”从上方进入 BUILD；星芒首次进入视野时轻亮一次后静止，减少动态效果时不播放。三个节点各自包含线性图示、标题和一句精简说明，不使用卡片边框。图示用同一套交易语汇表达三步：BUILD 将包含行情想法的气泡转为条件分支与 B/S 买卖动作；TEST 在简化 K 线上使用 B/S 标签、细引线及成交圆点，保留轻量回放进度；LEARN 对比两种交易结果，以放大镜强调差异并引出问号气泡。B/S 使用统一浅金底和品牌色字母，不沿用真实交易界面的红绿配色；图中不放收益数字或真实策略结论。桌面三列，标注“下一个假设”的回路线从 LEARN 全部图文下方回到 BUILD 下方；手机采用左图右文的三行，回路线沿左侧直接接入 BUILD，不回到初始想法。线路使用 `--color-diagram-connector`，星芒光晕使用 `--color-idea-glow`，由浅色／深色主题统一定义。金色仅点出阶段、方向和重点，不持续播放闭环动画。移除额外的结果总结句，保留次级业务边界。图示只说明研究方法，不展示模拟收益或交互界面。公开页样式集中于 `public.css`。

公共顶栏仅提供价格、语言与登录／工作台入口；手机将账号入口收进菜单，保留价格及语言。桌面与手机顶栏统一为 60px 并固定在顶部，正文预留同高空间；背景采用主题变量 `--color-bg-public-header`（画布色 82% 不透明度）和 12px 背景模糊，不加阴影或分隔边框。语言触发区域保持至少 44px，悬停、展开与键盘聚焦不变底色，以文字略微加深和箭头转向提示状态，按下轻微降低透明度；菜单选项沿用共享样式。公共语言菜单不锁住页面滚动，开合前后保留滚动条；价格、语言与账号入口分别固定为 64px、52px、112px，避免语言长度变化导致横向位移。380px 以下价格入口收至 56px，导航与 Logo 间距收至 6px；手机账号入口仍收进菜单。Logo 字标悬停保持原正文色，键盘聚焦用轻微透明度反馈。研究流程仅保留首页正文。页脚提供价格、隐私、条款与联系，不显示历史表现提示；开源入口放入服务条款，取消与退款合入价格页。隐私政策与服务条款正文宽 736px（不含外围留白），与价格问答共用 `--conversation-width`，标题、更新日期、正文自然排列，已填入运营者与邮箱时不显示草案，仅在信息缺失时保留轻量草案提示；联系信息由共享配置提供，不生成无效邮箱链接；隐私与条款正文只保留邮件链接，联系页入口统一留在页脚。政策分节可包含多段正文，段间留白 12px；用户声明及禁止行为使用轻量项目列表，条目间距 8px，沿用正文颜色与行高。价格页完整复用工作台订阅组件，标题、套餐／积分加购页签、卡片按钮位置和金额表单均一致，购买统一提示待上线；已登录时与工作台显示相同的当前套餐，访客显示禁用的免费套餐及 Free 加购单价示例，不提供研究跳转。套餐下方以五个短问答说明套餐差异、积分消耗、额度用完、续费取消与退款，上方增加居中的“常见问题 / Frequently asked questions”二级标题，问题使用三级标题。问答保留现有展开式正文，正文左对齐；内容最大宽 736px 并居中，手机两侧留白 20px。积分只解释消耗原则，不列模拟数值或逐项计价表；共享预览说明标明 USD 币种。

### 5.2 侧栏收起按钮（已确认）

- 放在左侧导航栏内部，Logo 右侧，与 Logo 同一水平线。
- 桌面不再在聊天 Header 左侧重复放收起按钮。
- 导航收起后，在侧栏原位置保留展开入口。
- 小屏因侧栏使用抽屉，保留 Header 的打开导航入口。

### 5.3 聊天内容宽度（已确认）

- 正文内容宽度以 **736px** 为基准，空间充足时保持该宽度并居中。
- 底部输入框与正文内容列对齐。
- 输入框悬浮在完整消息区域的底部，消息滚动条延伸到页面最底部，不再拆成上下两个独立区域。
- 消息底部留白按输入浮层的实际高度加 `24px` 计算，快捷问答展开或收起时同步更新，保证最后一条消息可完整滚出遮挡区。
- 输入浮层变高或变矮时只调整留白，不自动滚动背后的消息，允许暂时遮挡内容，避免打断输入；用户可手动滚动查看。
- 输入浮层上沿使用 `32px` 的画布色渐变，越往上越透明；渐变允许滚轮穿透，输入框保持可操作，回到最新消息按钮位于浮层上方，采用 `36px` 圆形按钮和 `20px` 向下箭头，不显示文字，保留无障碍名称。
- 736px 指内容区域，不包含外围留白。
- Markdown 表格统一占满正文内容宽度，不按内容收缩；超过可用宽度时仅表格区域横向滚动。
- 分屏或小屏空间不足时自适应缩小，不产生横向溢出。
- 当前桌面两侧最小留白 `30px`，小屏 `16px`，正文与底部输入使用相同留白和滚动条占位；分屏拖动、侧栏切换后两侧仍保持对齐。
- 落地页与新研究页输入区也采用同一 736px 上限，通过 `--home-width: var(--conversation-width)` 共享规格；窄屏随可用空间收缩。

### 5.4 聊天 Header（已确认方向，尺寸为本轮采用值）

- 压低高度，保留必要上下文和操作，减少空间占用。
- 工作台页头统一固定为 **48px**，新建页与对话页共用；左侧导航的 Logo 与展开/收起按钮同步居中，路由切换不改变导航条目的纵向位置。
- 背景与聊天画布相同，为 `#FAF9F6`。
- 移除硬分隔线；下沿使用同底色向透明渐隐，越向下越透明。
- 当前渐隐区域高 `22px`，不阻挡鼠标或触摸操作。
- Replay 展开后覆盖右侧 Header 区域，不在面板顶部继续预留全局 Header 的高度。
- 右上角资产入口为单个文件夹图标按钮，不显示常驻文字；默认次级文字色、透明背景，hover 为中性浅底及加深图标，延迟 400ms 显示“研究资产”提示；列表展开时采用 selected 浅赭金底与 brand 图标色，hover 保持 active 配色。点击区沿用桌面 32px、小屏 40px 的页头规范，颜色与短过渡复用语义变量，键盘保留可见焦点与无障碍名称。

### 5.5 侧栏、历史与品牌资源

- 新研究条目高 36px，历史条目高 32px。Hover、键盘聚焦和选中态共用 `--color-bg-sidebar-interactive`；新研究入口在 `/new-task` 有选中态。
- 收起后悬停显示完整导航预览，不推动正文、不增加右侧阴影或横向展开动画，顶部只保留展开按钮。点击固定展开/收起才带布局过渡；收起动画经过静止鼠标不重新触发 Hover，开关保持连续不闪烁。

## 6. 对话与输入交互

### 6.1 Agent 回复（已确认）

**回复前不显示 Logo，也不显示 “SpeakQuant” 名称，直接渲染内容。**

Agent 与策略 Design 共用 `MarkdownContent` 和 `main.css` 中的 `markdown-prose` 样式。Markdown 正文字号桌面为 `16px`、小屏（≤700px）为 `15px`，正文行高为 `1.625`，相邻普通内容块的段间距为 `0.75em`，随字号缩放；字号为 `16px` 时对应行高 `26px`、段间距 `12px`。标题、代码块行高及列表项间距沿用各自样式。

首字状态规则：

1. 请求已发出，但尚无第一个字符：在回答起始位置展示轻量 Loading 占位。
2. 收到第一个字符：立即移除 Loading，在同一位置开始渲染正文。
3. 后续流式输出：保留已输出内容，不同时显示 Loading，也不重新插入身份标题。
4. 历史完成的回复直接显示内容，不重演 Loading。

首字占位使用轻量 Spinner。原型演示中的 `650ms` 等待和后续定时分段输出只是模拟首字行为，**不是生产等待时长要求**。真实回复由返回内容驱动：少量文字连续出现，不做整段淡入或重复加载；已有段落、表格及代码块保持原位。用户上滚停止跟随，历史恢复不重演吐字。工具区生成期间保留单行最小高度，通过透明度切换提示，避免反复挤动内容。吐字队列、Snapshot 与滚动实现参数统一见 [Agent 对话模块技术方案 §8–9](./Agent%20对话模块技术方案.md#8-消息与卡片-ui)。

### 6.4 输入基础行为

- 输入框使用箭头发送按钮，不增加“验证策略”等按钮文字。
- 共享研究 / 消息输入框在默认、悬停和聚焦时均使用普通细边框 `--color-border-default`，不切换金色边框；悬停或聚焦时阴影切到主题变量 `--shadow-composer-active`，以 160ms 轻微加深，减少动态效果时直接切换。浅色活跃阴影为 `0 4px 22px rgb(48 49 46 / 7%)`。
- 空输入不可发送。
- Enter 提交，Shift+Enter 换行；中文输入法组合输入期间不误提交。
- 对话输入框最小 2 行，按文字实际显示高度（包含自动折行）增高或缩小，最多显示 16 行，超出后在输入框内部滚动。共享的新研究输入保留初始 3 行；粘贴、草稿恢复和分屏宽度变化时同样自动调整。
- 落地页与新研究页使用同一套 `ResearchEntry` 展示：最大宽度 736px，与对话页底部输入框共用宽度变量，默认隐藏键盘提示，输入框初始 3 行；外围标题、导航和页面布局分别保留。快捷示例统一使用细边框、12px 圆角、16px 内边距的卡片，赭金折线图标，悬停使用共享主题背景和边框色；桌面四列、760px 以下两列，卡片间距 12px、距输入框 18px。点击示例填入并聚焦输入框，允许编辑，不直接运行。

Clarification 使用底部逐题卡片，展开时位于普通输入框上方，普通输入框始终可见，与正文同宽；每次只显示一道题，顶部为题目、题号 / 总数、前后导航及关闭按钮；三个图标按钮悬停仅加深图标颜色，不显示背景块，保留原有点击范围与键盘焦点提示。选项以带数字标记的整行纵向排列，每项下方均显示细分割线，包括最后一项。选择后进入下一题，最后一题确认答案或 Skip 时统一提交；自定义回答采用底部轻量输入行，编辑图标为 12px，沿用选项数字的 24px 圆角底座，文字直接在图标后输入，右侧始终放置1px 细边框、透明背景的 14px 按钮，中文“跳过”、英文“Skip”，悬停仅加深文字颜色，不带箭头且不因当前答案为空而禁用；输入框无边框和金色焦点环，自定义输入行保持透明背景，不突出于快捷选项，鼠标移入和输入聚焦均不改变背景。占位文字为“输入其他回答，按回车确认”，使用 14px 常规字重、主题变量 `--color-text-placeholder`（浅色为 80% 的 muted 文字色），弱于选项和实际输入文字；实际输入保持 16px 主文字色。Enter 确认并继续、Shift+Enter 换行，输入法组合期间不前进；输入区最高 120px。每题均可 Skip，不区分必答 / 选答，不显示第二个跳过入口；末题 Skip 提交此前已填的有效答案，全部跳过也可结束问答（待后端支持，见接口文档）。卡片采用 `16px` 圆角、表面背景及细边框，选项行最小高 `48px`；小屏顶部导航与题目分行，卡片限高 `min(48dvh, 440px)`、选项内部滚动；卡片和普通输入框间距 12px，展开时普通输入最多显示 4 行，收起后恢复 16 行，避免挤占小屏空间。

- 常规分栏及窄屏覆盖详情面板上、右、下保留 **8px** 外边距，左侧分栏间隔保持 **4px**，桌面四角 **14px** 圆角，窄屏 **12px**。点击全屏后，Strategy / Replay 详情移至页面顶层，覆盖整个浏览器视口（包括侧栏和页头），无外边距、圆角、边框或阴影；退出全屏恢复原分栏宽度和阅读位置。

- 与聊天画布使用轻边框和极弱阴影区分，不增加厚重装饰。

### 7.2 回测内容与交互基线

- 回测标题下拉所有选项采用相同两行布局：名称、交易对 / 周期 / 回测起始日期；始终按回测创建时间逆序排列。选中项保留相同信息与尺寸，仅以勾选标记区分，不置顶。

- 回测内容滚动容器使用 `scrollbar-gutter: stable`，半屏及全屏均预留原生滚动条宽度，避免内容增减触发滚动条显隐时挤动图表与时间轴；覆盖式滚动条按系统行为显示。

- 桌面首次打开采用默认缩放：目标之前约 100 根 K 线、右侧 8 根宽度。无论从头播放、中途定位或回到最新，都按当前用户缩放判断已揭示历史是否铺满一屏：不足时首根靠左，K 线向右增长，填至默认右侧边距后自动跟随；保留用户已调整的 K 线宽度。进度条点击/拖动/键盘、买卖点、单根/区间洞察点统一只切换历史时刻：暂停、清除旧框选和交易/洞察选中态，保留用户 K 线宽度，历史不足一屏时采用上述左侧增长布局，铺满时将最后一根可见 K 线平移到绘图区约 93% 处，右侧约 7% 留白。事件点不自动框选、不增加定位竖线/价格线、不联动选中卡片；重复点击也只定位。保留查看周期，未来行情、交易、洞察隐藏，顶部指标同步截止位置。播放从该时刻继续时仍保留缩放。结果定位复用交易卡片的框选与条件平移，不自动缩放。桌面图内洞察和底部交易卡片保留用户当前缩放：洞察只框选，交易卡片框选后仅在区间末端不可见时平移，长区间可超出视野。再次点击已选中的交易卡片取消选中并移除框选，仅清除标记，保持位移、缩放、查看周期、播放进度和跟随状态；鼠标及键盘激活一致。

桌面回测控件不显示鼠标或键盘焦点外框，保留原有选中态。点击时间轴定位后可直接按空格播放/暂停，焦点无需转移到播放按钮；长按空格不连续切换，不滚动页面。输入框、菜单和阅读层不接管空格。此规则仅作用于回测工作区，手机保持原行为。

- 半屏、调宽、全屏及手机均以全宽 K 线为主体，不设置常驻右侧洞察栏。
- 一个历史截止位置决定可见范围，没有浏览/播放模式切换。默认末根；拉回过去同时隐藏未来行情、成交与洞察，暂停保持边界，播放从当前处继续。拉到末根即可查看全程。
- 桌面顶部六项指标随时间轴更新，新增末列“当前持仓”（空仓/持有多仓/持有空仓，读取当前主周期 state，缺失显示“—”）。指标按内容宽度均匀分布，末列标题和数值右对齐图表右边界；“查看详情”取消右侧内边距，与末列共用右边界。持仓数值为 400 普通字重，与其他指标一致；净收益率取消放大，所有指标统一 18px，窄容器统一 16px。结果标题采用纯文字：历史位置为品牌色“截至此时”，末端为弱化文字色“最终结果”；不使用图标、底色或胶囊外形，布局保持一致。取消图下重复状态行，仓位和浮动盈亏收进标题右侧“查看详情”，指标网格不再放孤立箭头。手机暂保留原结构。
- 回测详情头部只保留查看策略、全屏、关闭操作，移除更多按钮及其下拉菜单。运行包下载统一从策略详情头部进入，未具备下载来源时禁用。
- 桌面日期与条件入口并入标的/策略元信息首行，窄面板日期允许省略并通过悬停显示完整日期。
- 桌面图表左上角悬浮显示数字日期时间、开高低收、涨跌额/涨跌幅、成交量，紧凑单行排列，不换行；窄面板内可横向滚动，画布铺满图框，读数保持悬浮嵌入感，网格与十字线贯穿；使用价格轴顶部留白为行情和 TAG 让位，不将画布下移或拆出独立行情栏，图框保持原高度。成交量文字始终存在；柱图独立开关。桌面开高低收和涨跌额/幅数值跟随蜡烛开收方向使用 candle-up/down 红绿；中文字段简写“开/高/低/收”。成交量数值使用正文色和 500 字重，去除无意义末尾零，保留真实小数；日期和字段标题保持原样式。涨跌额/幅仍按前收计算，不改变正负号。周期按钮与图表共用背景和外边框，以细线分隔，窄桌面面板允许横向滚动。手机暂保留原布局。
- 桌面十字线时间标签和图下播放时间采用 `YYYY/MM/DD HH:mm`，中英文一致，十字线日期浮层采用浅灰底、深色文字和 5px 圆角，上下等量留白，与普通刻度的文字基线对齐；横轴日期刻度使用 `YYYY/MM/DD`，日内刻度使用 `HH:mm`。回测界面暂不显示 UTC 字样，时间值保持现有 API 基准。
- 桌面图表操作不暂停播放，单纯点击不改变跟随策略。右移后最新 K 线仍可见时，按当前较窄右侧留白继续跟随；最新 K 线完全移出右侧后保持视野。左移产生较大右侧留白时，保持位移，让新 K 线填充，到默认边距后自动跟随；暂停再播放沿用此状态，不重新定位；图内右下角“回到最新”保留缩放并恢复跟随，时间轴定位仍暂停播放，图内洞察和下方交易卡片检查保持原播放状态；B/S TAG 悬停显示订单明细，横向优先右、放不下才左，纵向优先上、放不下才下；按实际浮层尺寸独立判断四个方向。上方展示时上下间距 4px，右上左边缘对齐 TAG、左上右边缘对齐 TAG；下方展示时在 TAG 侧边相隔 4px，右下位于 TAG 右侧、左下位于 TAG 左侧，两者顶边对齐，保持贴近并限制在图内；主题表面、细边框和独立双层悬浮阴影，显示时间、买卖方向及数量@成交价，同根多笔逐行列出。鼠标可进入浮层停留和点击，离开 TAG 与浮层后延迟 220ms 关闭，不提供查看明细入口。图内洞察点击只作辅助检查：冻结当前视野以便阅读，但不暂停、不跳转进度；选中时填实圆点、框定证据，单根和多根区间都不缩放、不平移，圆点位置与用户视野保持不变，区间超出视野也不强制移回。再次点击取消高亮、恢复空心，保持播放状态和视野。时间轴洞察点击只暂停并跳转事件时间，清除原框选与选中态，不填实图内圆点；框选由图内洞察或交易卡片主动触发。时间轴单向决定图表可见内容。
- 成交采用实心圆角尖角 B/S TAG，带连接线和成交价锚点；B/S 对应实际买卖，同根同侧可合并为 B×n/S×n。明细以开多/平空等动作解释，不能仅靠颜色判断。
- 桌面图下左侧为时间，右侧为到开始、播放/暂停、到结束、倍速。播放/暂停仅显示中性色图标，保留 32px 点击区域，无边框、无底色、无常驻文字，与两侧跳转按钮统一 32px 区域及 18px 图标，垂直居中对齐；文字通过悬停提示显示，不使用金色底块。倍速按钮固定宽度 62px，文字在剩余宽度内右对齐，距下拉箭头 4px；切换 0.5x/10x 不移动周围控件。末根按钮为从头播放，其余为播放。倍速采用无常驻底色的文字加下箭头触发器和紧凑应用菜单，当前项勾选；鼠标点击无金色外框，键盘也不显示外框。默认速度为 1x，选项为 0.5x / 1x / 2x / 5x / 10x，不隐式压缩普通区间。手机暂保留原控制栏。
- 固定 Timeline 高 78px，顶部日期刻度、单轨彩色买/卖/洞察点、贯穿轨道的时间指针。桌面买/卖/洞察分别水平对齐，按实际时间独立显示和点击，不合并；悬停轻微放大圆点，无块状背景；桌面洞察点额外显示可移入阅读的洞察浮层。手机保留原点组交互；没有裸数字或额外轨道。颜色使用 chart-buy/sell/insight 主题语义变量并配紧凑图例；洞察点与图例统一使用蓝紫色（浅色 #7165bf、深色 #a99ae8），与买卖红绿及时间指针赭金区分。
- 桌面实时洞察以 16px 紫色空心圆圈与灯泡图标固定在图内底部同一水平线，选中填实圆圈并反白图标，命中区域保持 20px，横向随对应 K 线移动；悬停显示白色内容浮层，细边框和主题悬浮阴影，允许移入阅读，播放经过不自动展开。洞察按自身 K 线或明确区间表达，不要求对应一轮交易；选中洞察时交易卡片不联动高亮或滚动，也不带出交易价格线。关联交易只在用户主动打开时选中。底部不重复实时洞察列表，暂不展示总结洞察。
- 桌面交易使用 168px 宽、约 88px 高的紧凑横向卡片，固定从左到右按时间正序，与图表一致，不提供排序和常驻方向/离场筛选；显示方向、17px 收益率主值、12px 净盈亏金额次值和单行简短日期，不显示编号。区域标题使用“交易”，每张卡片表示一轮持仓过程（也含未平仓），具体买卖称“成交明细”。点击主体只切换框选，保持播放状态、回放进度与当前缩放比例，并解除视野跟随；交易结束 K 线已在实际绘图区内时不平移，不在时将结束 K 线平移到绘图区宽度约 70% 处，左侧留出交易历史、右侧留出后续走势空间。未平仓交易以当前回放位置作为区间终点，播放时框选随持仓延伸，平仓后终点固定，不自动移动视野；不要求起点或整个区间都可见，长区间可超出视野；右上角常驻轻量“明细”按钮打开独立弹窗，不在卡片下方展开内容。“明细”悬停只改变文字颜色，不增加底色。弹窗最大宽度 1180px，收益率 28px 为主、净盈亏 20px 次之，持仓/离场信息并排；进出场价格、数量与毛利润放在次级指标行，各项费用集中为常显轻量行。指标组之间不用分割线。下方成交表保持一笔一行，仓位变化与原因各占一列；数字、时间不换行，长原因单行省略，悬停 400ms 或键盘聚焦显示完整文本。提示层使用 12px 字、主题表面色和轻阴影，无重背景交互；关闭后保留原视野与选中卡片。手机保留洞察/交易 Tab。内容和计数随截止位置揭示，未平仓不显示未来盈亏或 Fill。卡片带默认贴右跟随最新已揭示交易，手动向左浏览后保持当前位置；暂停再播放保留跟随选择。脱离右端时标题行右侧显示轻量“回到最新”文字与双箭头，点击平滑回到右端并恢复跟随，手动滚回最右侧也恢复跟随；按钮无底色和强调边框，显隐不改变卡片带高度。连续横向滚动不在每 20 笔交易处中断，采用局部渲染控制大样本 DOM。
- 暂停可切后端支持的查看周期，辅助周期只显示截止时已收盘 K 线；播放切执行周期。顶部指标随时间轴更新，查看周期切换不改变业务口径。
- 策略收益率与当前/最大回撤显示百分数 4 位小数，计算保留完整 Decimal 精度；资金基于当前主周期收盘权益，指标详情展示当前权益/现金及可验证的回撤峰值、谷值权益与采样时间。费用不重复扣减。条件仅对冻结的 equity_percent=1 显示“全仓 · 连续复投”，旧比例照实显示，无新增表单入口。回撤阴影只表达时间跨度，不以币价高低点表示权益回撤；历史位置使用当前前缀，终点数字使用后端结果，不一致时隐藏区间。
- 桌面最大盈利/亏损/回撤收进图表工具栏固定的“结果定位”菜单，与交易卡片共用交互：保留播放、进度和缩放，框选区间；末端已可见不平移，屏幕外则平移至绘图区约 70% 处。盈利/亏损选中对应交易，最大回撤仅选区间；尚未揭示的区间禁用，入口不随截止点显隐。
- 桌面 K 线涨绿 #2ebd85、跌红 #f6465d，成交量使用对应透明色；配色由 light/dark 主题的 chart-candle-* 变量维护，手机和收益指标文字沿用原色。工具栏不再提供重置缩放入口。图内右下角按实际位移显示“回到最新”：28px 轻量中性细边按钮、18px 双右箭头 chevrons-right，悬停仅略微加深图标色；位于价格轴左侧、洞察圆点上方。点击保留缩放，以 260ms ease-out 平移至当前历史截止点的最后一根可见 K 线并恢复跟随，不改变进度、不启动或暂停播放、不清除框选。动画期间继续追随新增 K 线，用户再次拖动或缩放立即中断；减少动态效果设置下直接到位。不足一屏时，默认左对齐布局不显示返回按钮，用户实际移离该位置后才显示；铺满后，只在右侧留白大于默认值或最新 K 线完全离开右侧可视区时显示，末根仍可见且留白等于或小于默认值时隐藏。按钮不因鼠标按下、点击或聚焦而出现；返回时依然按当前历史长度和缩放恢复左侧增长或右侧跟随。
- 图表关闭内置 TradingView Logo；公开 `/open-source` 及 `public/licenses` 保留署名/链接/许可证。
- 手机优先净收益、回撤、笔数。条件、报告使用按需阅读层；追问引用进入聊天草稿并由用户发送。全屏及策略往返保留位置，返回暂停。

### 7.3 策略详情

策略 Header 高 44px，左侧单行变更摘要与上下箭头组成一个整体单选入口，右侧保留全屏和关闭。入口桌面高 30px、小屏 36px，最大宽度 560px，并随可用空间收缩；标题 14px / 20px，长摘要单行省略。默认无边框和底色，悬停及展开时整个区域使用中性浅底，键盘聚焦有清晰轮廓，点击标题或箭头均打开同一下拉。折叠标题与下拉选项均优先 `change_summary`，缺失才回退到策略名；策略名放在下拉辅助行和悬停提示中。完整摘要可在下拉或提示中阅读，不增加副标题或正文重复摘要；标题提示与辅助技术描述保留当前标识/本地形成时间。

下拉宽 320px、最大不超过视口减 24px，外内边距 6px、项内边距 10px / 12px、项间距 4px。所有摘要左对齐，主行 14px / 20px、500 字重，可换行；次行策略名 12px / 16px、muted 色，与主行相距 4px，过长单行省略。当前项固定首位，不增加“当前”标记。次行右侧以 11px muted 小字显示月/日与时分，使用本地时区，完整日期放在时间提示中；策略名与时间同一行，名称过长省略。当前时间来自 `updated_at`，历史时间来自 `formed_at`。回测状态、次数不在选择器重复。右上侧勾选表示选中，所有项预留 15px 勾选空间以保持文字、时间对齐，仅悬停/键盘焦点使用浅底，不给选中项常驻卡片底色；无分组分隔线。无摘要旧记录以名称为主、时间为次行，保持两层；没有次级名称时，时间左对齐。菜单 Portal 层级为 51，高于全屏面板的 50。全屏与关闭按钮：桌面 30px、小屏 36px，图标 17px，6px 圆角，悬停使用中性语义底色；聚焦及 Esc 返回后仅轻微加深图标，不画外圈、不新增边框或阴影；不套用全局 40/44px icon-button。Tooltip 延迟 400ms，按钮不使用原生 title 重复提示。仅从策略进入 Replay 后显示返回策略按钮；Replay 保持 44px 单行 Header。

主体采用设计（中文）/ Design（英文）、回测记录、代码三个 Tab，使用图标与文字、36px 紧凑按钮和中性选中底色，去掉下划线及整条底部分隔线，避免与 Header 边框叠出两条横线。正文左右 20px，窄面板 16px，保持一个主滚动区；Design 最大宽度 660px，回测记录（包含范围工具栏）最大宽度 1120px，两者均居中并随窄面板收缩；代码使用可用全宽。Design 直接复用 Agent 正文的共享 Markdown 排版（见 §6.1），不新增分节卡片；正文直接从 Markdown 标题开始；复制按钮位于正文末尾右侧，仅修改未回测时在同一行左侧以 muted 小字显示“修改后未回测”，不在正文上方增加工具栏或重复已回测状态。代码显示行号、语法高亮、横向滚动和复制，不放在线编辑或执行控件。

回测使用可整行点击的紧凑记录列表：图表图标、单行标题、标的、周期标签和日历区间形成左侧信息组；净收益用较大的数字、涨跌方向图标及语义颜色突出，回撤与交易次数作为对齐的次级指标。取消独立表头与表格网格线，悬停使用轻底色。范围工具栏与记录行使用一致的左右内边距，左侧计数与记录图标对齐，右侧切换与最右指标对齐；交易次数右对齐。右上角以图标与文字切换查看全部/仅看所选版本。取消右侧箭头。全部模式的版本归属放在回测标题同行，不增加第三行；匹配所选策略节点的行仅显示品牌色勾选与“所选版本”，不增加行背景，其他行显示分支图标及节点摘要，缺少摘要时回退到名称。版本信息最多占标题行 40%，长文本省略、悬停可查看完整内容。760px 及以下面板将指标移到条件下方，保持三列比较，不撑宽页面。无交易和加载失败均用必要的短文案，不添加常驻说明或功能介绍。版本和范围行为见[策略详情模块技术方案](策略详情模块技术方案.md)。

## 8. 动效与形状

已确认原则：**克制但不死板。**

当前原型可参考的反馈：

- 研究 / 消息输入框沿用普通细边框，聚焦不变为赭金；此项以当前实现为准。
- 主按钮悬停略加深，按下有轻微缩放。
- 策略示例和入口箭头有轻微位移反馈。
- 过程展开、面板出现、事件选中有短促、可理解的变化。
- 支持 `prefers-reduced-motion`，减少非必要运动。

列表与详情分别使用 `--motion-asset-list` / `--motion-asset-detail`，当前均继承 `--motion-panel`（260ms），后续可独立调整：展开从右向左滑入，收起反向滑出，关闭动画结束后再隐藏；桌面正文空间同步过渡，面板内容保持目标宽度，避免反复折行。列表卡片与聊天卡片打开详情时，均由详情组件执行同一段从右向左的滑入；原列表独立向右收起，不先把聊天恢复全宽，也不在窄列表里直接替换详情内容。边框调宽不带缓动；全屏和小屏沿用同一方向，减少动态效果偏好下跳过过渡。其余控件复用全局动效变量。不要通过长动画、重复脉冲、收益庆祝效果或持续旁白增加噪声。

## 10. 正式产品仍需打磨的内容

1. **深色主题**：未来提供浅色、深色与跟随系统；目前仅浅色完成方向探索，现存脚手架 `.dark` 样式不代表已设计的深色方案。
2. **字体与可读性**：中英文字体一致性、字体授权、文字对比度、小字号、缩放和不同平台表现。
3. **组件完整状态**：Hover、Focus、Active、Disabled、Loading、空态、错误、重试与网络中断。
4. **真实流式对话**：首字、停止、失败、断线恢复、工具事件、滚动跟随和用户主动浏览历史的关系。
5. **Replay 完整交互**：真实缩放和平移、洞察精确定位、事件聚合、首轮自动回放、关键事件停留及位置恢复。
6. **布局细节**：分隔线拖动、不同屏幕尺寸、移动键盘、安全区、顶部渐隐与滚动内容的关系。
7. **完整业务**：资产列表、Strategy 历史与恢复、真实登录、Runner 下载等，按 PRD 补齐。
8. **数据语义**：真实费用、数据区间、延迟、风险及验证来源，不能用演示数字支撑真实结论。
9. **代码与验证**：组件拆分、统一设计 token、浏览器交互验证和无障碍验证。当前通过构建及类型检查，并不等于完成全面视觉与交互验收。
10. **内容收敛**：持续检查是否重复解释、重复强调；原型中的示例文案、Logo 图形和标题尚不能视为全部品牌资产已定稿。
