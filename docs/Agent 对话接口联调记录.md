# Agent 对话接口联调记录

日期：2026-09-08。前端 `localhost:6002`，真实后端 `localhost:6001/api`。

## 已接入范围

- `/new-task`、落地页与可复用 `ResearchEntry` 接入真实研究创建。访客明确发送后先登录，再继续一次创建；仅输入、示例填入、普通登录或取消登录不会自动创建。
- 会话内普通文字发送、Markdown 流式回复、临时工具状态、消息卡片、历史分页和 Run 恢复。
- Clarification 在输入框上方显示，统一使用 `structured_answers`；HTTP 返回 `updated_messages` 后即时更新原题与答案。题目选择和普通文字草稿分别保存。
- 用户消息直接以普通气泡出现，只有失败才显示失败入口。整个回复期间可编辑输入，不能发送，也没有暂停/停止按钮。
- Strategy / Replay 卡片打开资产侧边面板；资产索引读取真实概要。详情、图表、策略/回测执行操作及 Runner 本期不接入。

实现集中在 `app/features/conversation/`：`useConversation` 编排接口和生命周期，`useAgentRun` 负责订阅与恢复，`agent-events` / `message-state` 处理事件验证和消息更新；界面由独立的 `UserMessage`、`AssistantMessage`、`MessageComposer`、`ClarificationQuestions` 与资产面板组合。面板开关不重建对话实例。Markdown 复用 `marked` 与 `sanitize-html`。

## 真实接口观察

使用独立临时账户和真实后端认证会话，经后端 `/auth/refresh` 恢复登录。临时账户由本地测试脚本初始化，不发送验证邮件，也不将本次验证描述为真实 Google 授权验证。Token 和 Cookie 仅在脚本/浏览器内存中使用，未写入工程文件、截图或日志。完成后清理临时账户及其研究数据。

## 实测修正

1. 面板需要覆盖右侧页头区域。去掉会话容器的裁剪后，面板关闭/全屏按钮能够正常点击；移动端面板层级高于侧栏展开按钮，不再重叠。会话页头采用设计文档的 44px 高度。
2. 提交时使用脱离 Vue Proxy 的冻结请求体，避免 `structuredClone` 无法复制响应式答案对象。重试保留相同正文、来源消息和幂等 key。
3. 普通文字进入下一轮后，旧的未答题不再出现在输入框上方，也不伪装成已答；原消息保留只读问题记录。上拉旧历史不会激活旧问题。
4. 取消访客登录撤销自动继续标记并恢复可编辑草稿。创建期间新输入的草稿衔接到新会话；登录续发的正文与幂等 key 不进入 URL。
5. Nuxt 类型生成曾误引用本机父目录的 Vue 3.2 类型；配置改为从本项目 Vue 依赖解析 runtime-core/compiler-sfc，保持运行时与类型版本一致。

后端正文 schema 已核对：去除首尾空白，长度为 1–20000 个 Unicode 字符。快捷答案使用题目 ID 和原始选项文本；自定义回答去除首尾空白，最长 2000 字符，单题与多题均使用数组。

测试数据仅存在于 `tests/` 的 HTTP 拦截与浏览器流式传输夹具中，生产代码不导入 Mock。

- 单元测试覆盖 Unicode offset、重复/缺口/部分重叠、坏事件、Snapshot 替换范围、历史顺序、卡片整体替换、工具与失败收尾、多题校验及旧题不重新激活。
- 浏览器测试覆盖新建、分段展示、纯文本与 Markdown 安全、回复期间禁止发送、双题一次提交、用户消息失败重试同 key、EOF 恢复原 Run、消息分页、草稿隔离、题目选择刷新恢复、取消登录和创建过程草稿衔接。
- 同一组浏览器流程在桌面与移动端执行；原有认证、研究历史、账户与工作台回归也执行。

2026-09-08 流式展示调整使用模拟 SSE 在桌面与移动端验证：单包 1080 个汉字逐步显示，每帧增量不超过 4 个字，Run 终态不一次性补齐展示队列；已有 Markdown 节点和代码块横向滚动位置保持，工具空占位高度为 20px，手动上滚停止跟随，历史刷新直接恢复全文。专项 8 项通过。会话回归首次 30 项中 29 项通过，1 项取消登录用例因 Google 测试按钮不可用超时；该项在桌面与移动端复测通过。相关单测 18 项通过。此轮没有测量两个项目真实后端的 SSE 片段大小和到达间隔，不将前端模拟测试解释为后端吐字速度的证据。

故障注入与真实链路分开判断：响应丢失后的恢复、所有后端错误码、Redis 状态过期、多标签页竞争和大规模长会话尚未逐一用真实服务触发。本次接口真实观察不代表这些故障均已完成真实验证。

## 保留边界

研究和快捷回答草稿、未决提交记录保存在当前标签页的 sessionStorage，并按用户隔离。记录不含 Token、历史消息或 SSE 数据。结果不明的请求保留原 key 供重试，明确拒绝后才能直接返回编辑；超出幂等时限时提示先核对历史。浏览器禁用存储时，当前页面内仍能提交与重试，但整页刷新后的草稿和未决请求恢复无法保证。

侧边面板当前只展示真实卡片/资产概要与详情占位，不提供未实现的回测、策略修改、下载或交易操作。暂停回复和自动排队均未开放。
